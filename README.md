# local-cast · 本地开源投屏工具

手机投屏到电脑的本地化工具：**投屏码 / 二维码连接，同一局域网 WebRTC 点对点直连**，媒体流不经过服务端，延迟低、无云端依赖，代码全开源。

## 特性

- 🔢 **投屏码连接**：电脑端生成 6 位投屏码，手机端输入即连
- 📱 **二维码扫码**：手机扫码自动打开投屏页，即扫即连
- 🖥️ **局域网直连**：WebRTC 点对点传输，媒体不经过服务端
- 🎬 **平台无感**：基于系统屏幕采集，红果、抖音、bilibili 等任意 App 画面均可投（第一阶段以红果验证）
- 🌐 **主流浏览器兼容**：Chrome、Edge、百度浏览器、vivo 浏览器等 Chromium 内核浏览器直接支持；微信等 X5 内核浏览器提供明确引导
- 📴 **完全本地**：无云服务、无 CDN 依赖，前端资源全本地化

## 快速开始

### 1. 启动服务

```bash
npm install     # 首次运行安装依赖
npm start       # 或双击 start.bat（Windows 一键启动）
```

### 2. 电脑端

浏览器打开 **http://localhost:8080/**，页面显示投屏码与二维码。

### 3. 手机端

- **方式一（推荐）**：用手机扫码工具扫描电脑端页面上的二维码，自动打开投屏页
- **方式二**：手机浏览器访问 `http://<电脑局域网IP>:8080/cast`，输入 6 位投屏码

### 4. 开始投屏

点击「开始投屏」→ 在系统弹窗选择「整个屏幕」并授权 → 画面实时投到电脑端，可全屏观看。

> 提示：投屏能力取决于手机端浏览器，建议使用 **Chrome、Edge、百度浏览器、vivo 浏览器**等 Chromium 内核浏览器。微信内置浏览器（X5 内核）不支持屏幕采集，请在页面右上角「···」→「在浏览器中打开」后选择上述浏览器。投屏期间请保持手机与电脑在同一局域网。

## 浏览器兼容性

| 浏览器 | 内核 | 投屏支持 | 说明 |
|---|---|---|---|
| Chrome | Chromium | ✅ 原生支持 | 推荐，兼容性最佳 |
| Edge | Chromium | ✅ 原生支持 | 推荐 |
| 百度浏览器 | Chromium | ✅ 原生支持 | 直接可用 |
| vivo 浏览器 | Chromium | ✅ 原生支持 | 直接可用 |
| UC / QQ 浏览器 | Chromium/X5 | 视内核版本 | 页面会自动识别并提示 |
| 微信内置浏览器 | X5 | ❌ 不支持 | 页面提供「在浏览器中打开」引导 |
| iOS Safari / 微信 | WebKit | ❌ 不支持 | iOS 系统限制，需使用 Android 手机 |

手机端页面会自动识别浏览器内核并给出针对性提示，无需手动判断。

## 工作原理

```
手机端页面 ──(信令: 投屏码匹配/SDP/ICE)──► 信令服务 ──► 电脑端页面
手机端页面 ──(媒体: WebRTC P2P 直连)─────────────────────► 电脑端页面
```

1. 电脑端打开接收页，向服务申请**投屏码**，服务生成二维码（内容为带码的投屏链接）
2. 手机扫码/输码连接，服务校验投屏码并匹配两端会话
3. 两端通过信令服务交换 WebRTC 协商消息，随后媒体流**点对点直连**，不经过服务端
4. 手机端通过 `getDisplayMedia` 采集屏幕（任意 App 画面），电脑端接收并全屏播放
